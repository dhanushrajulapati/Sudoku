# 🧩 Sudoku Game

A classic web-based Sudoku game built with HTML, CSS, and JavaScript. Enjoy solving randomly generated puzzles with a clean interface and subtle background effects.

## 🎮 Features

- ✅ Interactive 9x9 Sudoku board
- 🔢 Click-to-select numbers and tiles
- ❌ Error counter for wrong moves
- ♻️ Random board generation (with plans for dynamic puzzle generation)
- 💅 Polished UI with modern number buttons and masked grid background
- 🌐 Fully responsive and mobile-friendly
